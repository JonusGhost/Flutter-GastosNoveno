Características principales
Registro de gastos : Añade y edita tus gastos de forma sencilla.
Categorización : Organiza tus gastos en categorías como alimentos, transporte, entretenimiento, etc.
Gráficos y estadísticas : Visualiza tus hábitos financieros con gráficos interactivos.
Compatibilidad multiplataforma : Funciona en Android, iOS, Windows, macOS, Linux y Web.

Cómo ejecutar el proyecto
Asegúrese de tener Flutter instalado en su máquina. Descargar Flutter
Clona este repositorio:
intento

Copiar código
git clone https://github.com/tu-usuario/Flutter-GastosNoveno.git
Navega al directorio del proyecto:
intento

Copiar código
cd Flutter-GastosNoveno
Instale las dependencias necesarias:
intento

Copiar código
flutter pub get
Ejecuta la aplicación:
intento

Copiar código
flutter run
